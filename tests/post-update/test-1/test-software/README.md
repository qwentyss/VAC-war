# Test Software

## Purpose

This software build is used to test **Theory 1** in the CS2 VAC behavior research.

The software and its identifying names have been renamed for the experiment to investigate whether the naming changes correlate with the observed anti-cheat behavior.

## Test Scope

- **Research stage:** Post-update
- **Target hypothesis:** Theory 1
- **Test status:** Pending

## Experimental Notes

- Record the exact source revision and build used during each test session.
- Document any changes made to the software before or during testing.
- Record observations separately from interpretations.
- A lack of an immediate ban does not establish that the software was undetected.

## Disclaimer

This repository documents an experimental hypothesis. Renaming the software alone does not establish that process-name detection exists or that the change affects VAC behavior. Conclusions must be based on recorded observations and further verification.
